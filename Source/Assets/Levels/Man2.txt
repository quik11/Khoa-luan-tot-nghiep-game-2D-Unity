// MÀN 2 - "Leo tường, bắn tơ qua vực"
// Dựng scene: Unity > menu trên cùng Brand NEU day > Dựng màn từ file chữ... > chọn file này.
// Sửa map: đổi ký tự rồi dựng lại (scene Man2 cũ sẽ bị ghi đè).
//
// Ký hiệu: # đất   . trống   P xuất phát   E Quỷ Gối   F quái bay tuần tra ngang   V quái bay tuần tra dọc
//          + đùi gà   a đạn tơ (1 lần)   A trạm hồi tơ (tự hiện lại)   B sách nâng cấp   D cửa qua màn
//          C điểm lưu (chết thì hồi sinh ở điểm lưu chạm gần nhất)   X vùng chết ở đáy vực (chạm là chết ngay)
// Mỗi ký tự = 1 ô. Dòng trên cùng của bản đồ = hàng cao nhất. Nhân vật cao 2.5 ô, rộng 1 ô.
//
// Các đoạn (đếm cột từ trái, bắt đầu từ 0):
//   cột 2-13    chỗ xuất phát
//   cột 14-31   sân 1: 2 Quỷ Gối đi cạnh nhau (chém 1 nhát trúng cả 2) + 1 quái bay cao 5 ô
//   cột 32-48   2 vực chết rộng 5 cột (cái sau phải nhảy lên bệ cao hơn 3 ô) -> điểm lưu 1 ở đáy giếng (cột 57)
//   cột 49-64   giếng bật tường rộng 4, cao 14 ô; lên tới đỉnh rẽ trái là có sách nâng cấp
//   cột 65-77   sân 2: Quỷ Gối + quái bay
//   cột 78-107  điểm lưu 2 ở cột 87 (trong hầm), hầm trần thấp: không nhảy qua vực được, đứng sát mép bấm Q bắn tơ vào khối bên kia
//   cột 108-136 điểm lưu 3 ở cột 109, vực dài 10 cột ngoài trời: chạy sát mép, nhảy giữ Space, gần đỉnh bấm Q bám vào tường cao
//   cột 137-162 điểm lưu 4 ở cột 137, sân cuối: Quỷ Gối + quái bay, cửa qua màn
// Trước mỗi vực bắt buộc tơ kéo có 1 trạm hồi tơ (A); hồi sinh cũng được nạp đầy tơ nên không bao giờ kẹt vì hết tơ.
